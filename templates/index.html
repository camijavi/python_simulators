Pila (Stack)

  • Principio: LIFO (Last-In, First-Out)
  • Inserción: push(item) en el Tope
  • Extracción: pop() del Tope
  • Acceso: Solo al elemento superior (Tope)
  • Ordenamiento: Secuencial cronológico inverso
  • Duplicados: Permitidos
  • Complejidad: O(1) Push, O(1) Pop, O(1) Peek
  • Estructura Python: list con append() y pop()

Cola (Queue)

  • Principio: FIFO (First-In, First-Out)
  • Inserción: enqueue(item) al Final (Rear)
  • Extracción: dequeue() del Frente (Front)
  • Acceso: Solo al elemento más antiguo (Frente)
  • Ordenamiento: Secuencial cronológico normal
  • Duplicados: Permitidos
  • Complejidad: O(1) Enqueue, O(1) Dequeue
  • Estructura Python: collections.deque con append() y popleft()

Lista Enlazada Ordenada

  • Principio: Orden Ascendente Estricto
  • Inserción: En la posición ordenada correcta
  • Extracción: Cabeza, cola o cualquier valor
  • Acceso: Mediante punteros next
  • Ordenamiento: Siempre organizado (ascendente)
  • Duplicados: No permitidos (según teoría de clase)
  • Complejidad: O(N) Inserción, O(N) Eliminación por valor
  • Estructura Python: Clase Node con puntero self.next
Pila en Python (LIFO) O(1) 
class Pila:
    def __init__(self):
        self.items = []

    def push(self, x):
        self.items.append(x)  # O(1)

    def pop(self):
        return self.items.pop()   # O(1)

    def peek(self):
        return self.items[-1]    # O(1)
Cola en Python (FIFO) O(1) 
from collections import deque

class Cola:
    def __init__(self):
        self.items = deque()

    def enqueue(self, x):
        self.items.append(x)    # O(1)

    def dequeue(self):
        return self.items.popleft() # O(1)

    def peek(self):
        return self.items[0]       # O(1)
Lista Enlazada Ordenada O(N) 
class Nodo:
    def __init__(self, val):
        self.val = val
        self.next = None

def insertar_ordenado(head, val):
    # Revisa duplicados y ubica posición
    nuevo = Nodo(val)
    if not head or val < head.val:
        nuevo.next = head
        return nuevo
    curr = head
    while curr.next and curr.next.val < val:
        curr = curr.next
    nuevo.next = curr.next
    curr.next = nuevo
    return head
Nota Teórica de Clase (read.me): En una lista enlazada ordenada, cada nodo almacena un valor y una referencia next al siguiente nodo. Para insertar o eliminar manteniendo el orden ascendente, se recorre la lista comparando valores. Si el elemento a insertar ya existe, se rechaza la operación para garantizar la unicidad de datos.
