🥞 Stack (LIFO)

  • Acronym: Last In, First Out
  • Insertion: Push (added to Top)
  • Deletion: Pop (removed from Top)
  • Pointers: Single pointer (`Top`)
  • Analogy: Stack of cafeteria trays, pile of books
  • Efficiency: O(1) Push, O(1) Pop, O(1) Peek
  • Python Type: list with append() and pop()

🚶 Queue (FIFO)

  • Acronym: First In, First Out
  • Insertion: Enqueue (added to Rear / Back)
  • Deletion: Dequeue (removed from Front / Head)
  • Pointers: Dual pointers (`Front` and `Rear`)
  • Analogy: People waiting in line at a cinema or bank
  • Efficiency: O(1) Enqueue, O(1) Dequeue (using deque)
  • Python Type: collections.deque with append() & popleft()
Python Stack (using list) O(1) Time 
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)  # O(1)

    def pop(self):
        if not self.items:
            raise IndexError("pop from empty stack")
        return self.items.pop()   # O(1) from end

    def peek(self):
        return self.items[-1]    # O(1)
Python Queue (using collections.deque) O(1) Time 
from collections import deque

class Queue:
    def __init__(self):
        self.items = deque()

    def enqueue(self, item):
        self.items.append(item)    # O(1) at rear

    def dequeue(self):
        if not self.items:
            raise IndexError("dequeue from empty queue")
        return self.items.popleft() # O(1) from front!

    def peek(self):
        return self.items[0]       # O(1)
⚡ Why collections.deque instead of list for Queue? In Python, calling list.pop(0) takes O(N) time because all subsequent elements must be shifted in memory. collections.deque is implemented as a doubly linked list of blocks, making popleft() true O(1)!

🥞 Stack Applications

1. Function Call Stack & Recursion

Operating systems and compilers use a call stack to keep track of active functions, return addresses, and local variables.

2. Undo / Redo Mechanism

Every keystroke or action in text editors (VS Code, Word) is pushed onto an undo stack. Pressing Ctrl+Z pops the latest state.

3. Balanced Parentheses & Expression Parsing

Compilers use stacks to match braces { [ ( ) ] } and convert infix expressions to postfix (Reverse Polish Notation).

4. Browser Navigation History

Every time you click a link, the URL is pushed to the back-stack. Clicking "Back" pops the current URL to reveal the previous one.

🚶 Queue Applications

1. Breadth-First Search (BFS)

Graph and tree traversal algorithms use queues to visit neighbor nodes level-by-level before going deeper.

2. Asynchronous Message Brokers

Technologies like RabbitMQ, Apache Kafka, and Celery buffer messages and job tasks in queues for worker processing.

3. CPU Process Scheduling

Operating systems organize runnable processes in ready queues using First-Come First-Served (FCFS) or Round Robin.

4. Hardware & IO Buffering

Printer spoolers, keyboard buffer keystrokes, and audio streaming pipelines buffer packets in FIFO order.
